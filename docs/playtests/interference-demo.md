# 雙曲干擾 Demo 驗證

測試對象為本機的 Demo 分支，未驗證遠端 Pages 部署。Chromium 使用真實 Apple 音訊並保留 HTTPS 驗證，手機尺寸為 390 × 844。

15 項 Node 測試通過：久石讓七個近似名稱的 3／4 或 4／3 分配、所有普通歌曲的可播放干擾選項、兩秒門檻、70% 相對音量、提早停止及延遲播放承諾的停止保護。

真實瀏覽器完成一輪十題久石讓干擾模式。干擾音觸發時，原曲播放進度介於 2.001–2.090 秒；原音量 80% 時干擾曲為 56%，改為 40% 後干擾曲為 28%。

額外確認：選真正的干擾曲仍判錯；原曲才得分；十二秒逾時、提早作答都停止兩首；尚未滿兩秒就作答不會事後冒出干擾；第二音源失敗時不開始計分，重試後可恢復；普通歌曲可真實雙曲播放；一般模式不產生第二音源。無 JavaScript 錯誤。另重跑一般單曲模式的久石讓專項回歸，20/20 首真實播放、八個原有近似選項與正解判斷皆通過。
